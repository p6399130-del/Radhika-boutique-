Radhika Boutique — Owner Controlled Store
============================================
यह एक working owner-control prototype है:
- Product add/edit/delete
- फोटो upload (browser में save)
- price, category, size, stock, description
- WhatsApp order
- Store settings
- JSON backup/import

महत्वपूर्ण:
यह अभी single-browser prototype है। असली live e-commerce में secure admin login,
cloud database, image storage, order management और payment gateway backend जोड़ना होगा।
Payment credentials कभी HTML/JavaScript में न रखें।

Live करने के लिए इस folder को hosting पर deploy करें और backend/database जोड़ें।
